# Moza Man Boost

Cria uma página de vendas de venda direta para um produto físico masculino, direcionada a homens em Moçambique.

A página deve ser criada DO ZERO.

Use o screenshot anexado como referência visual principal para criar uma página de venda direta com aparência profissional, agressiva, masculina e focada em conversão.

==================================================
IDENTIDADE VISUAL
==================================================

- Fundo preto/cinza muito escuro.
- Cor principal: verde-lima vibrante.
- Cor secundária: dourado/ouro.
- Vermelho intenso para alertas e elementos de atenção.
- Texto branco e cinza claro.
- Design mobile-first.
- Conteúdo centralizado.
- Largura máxima aproximada de 480px no desktop.
- Tipografia forte, moderna e extremamente legível em telemóveis.
- Headlines grandes e impactantes.
- Botões grandes, arredondados e fáceis de tocar.
- Cards escuros com contraste elevado.
- Bordas discretas.
- Sombras suaves.
- Badges de atenção.
- Pequenos elementos visuais de direct response.
- Aparência premium e masculina.
- Não parecer site corporativo.
- Não parecer página de curso.
- Não parecer página de PLR.
- Não parecer SaaS.

A página deve ter aparência de uma página de venda direta de produto físico, semelhante à estrutura visual do screenshot de referência.
